## About This Repository

This repository contains my solutions, practice files, and exercises for **Harvard's CS50P – Introduction to Programming with Python**.

The course covers Python programming fundamentals starting from basic syntax and progressing toward advanced concepts in a regular weekly fashion for 10 weeks.
